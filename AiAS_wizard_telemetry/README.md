# AI Alignment & Builder Quest (AiAS_wizard_telemetry)

A React + TypeScript onboarding wizard designed as a game-like mission flow.

## Features
- 8-chapter onboarding quest structure
- Modular question components (single/multi, sliders, rank-order, text, pledge)
- Telemetry utility + provider with analytics-friendly payloads
- Save/resume via localStorage
- Derived profile scoring (archetype, maturity, autonomy, guardrails)
- Rewards system with XP, streak, badges
- Completion reveal + recommended actions
- Mock admin analytics dashboard for telemetry and dropoff monitoring

## Run
```bash
npm install
npm run dev
```
