# Agent Tasks Pipeline (Beginner-Friendly)

## Core concept
A user describes what they want in plain English, and the system automatically builds an agent task pipeline to execute it—like Zapier, but designed for beginners.

## One-line pitch
"Describe your goal, and we build the workflow for you."

## Example user story
As a non-technical user, I can type: "When I get a support email, summarize it, create a task, and send me a Slack update," and the platform generates and runs the full pipeline without manual setup.
